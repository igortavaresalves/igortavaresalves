## About Me / Sobre mim

Backend developer and AI engineer focused on **LLM agents, RAG, API architecture and cloud integrations**, based in Recife, Brazil.  
Desenvolvedor backend e engenheiro de IA com foco em **agentes LLM, RAG, arquitetura de APIs e integrações cloud**, em Recife (PE).  

I build **LLM-agnostic AI agents**, RAG pipelines and agent evaluation (Arize Phoenix) on top of solid **Python, C#, TypeScript and React** foundations, with security and architecture in mind (RBAC, request throttling, injection protection).  
Construo **agentes de IA agnósticos de provedor**, pipelines RAG e avaliação de agentes (Arize Phoenix) sobre uma base sólida em **Python, C#, TypeScript e React**, com segurança e arquitetura em mente (RBAC, throttling, proteção contra injeção).  

**Open to work:** backend (Python/C#) and AI engineer roles, remote in Brazil or on-site in Recife.  
**Disponível para novas oportunidades:** backend (Python/C#) e engenharia de IA, remoto no Brasil ou presencial em Recife.
